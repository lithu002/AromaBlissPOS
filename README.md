# AromaBlissPOS 🕯️

AromaBlissPOS is a standalone Point of Sale (POS) and Inventory Management System developed for **AromaBliss Studio**, a boutique retail shop specializing in home fragrances.

Built with C# Windows Forms and SQLite, the application helps manage products, inventory, customers, sales transactions, and receipts without requiring an internet connection.

## ✨ Features

- 🔐 Staff login
- 📊 Dashboard with sales and inventory statistics
- 🛍️ Product and category management
- 📦 Inventory tracking and low-stock alerts
- 👤 Customer management
- 🛒 POS checkout with a shopping cart
- 💰 Discount and tax calculations
- 🔄 Automatic stock updates after completed sales
- 🧾 Receipt preview and printing
- 📋 Sales history and transaction details
- 🌙 Light and dark themes

## 🛠️ Technologies Used

- **Language:** C#
- **Framework:** .NET Windows Forms
- **Database:** SQLite
- **Application Type:** Standalone desktop application
